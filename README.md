# Kodigo

A free online compiler that comes with guides. Write code, run it in your browser, and learn as you go, with nothing to install.

**Status:** Phase 1 is done and the site is live. You can open it, pick Java, write code, and run it. Programs that read input are the next thing to build.

## Works now

- Java 21, compiled and run in your browser with the real `javac`
- Output and errors shown separately, and compile errors get red marks in the editor and clickable line numbers
- A Stop button for programs that never finish
- Code runs in your browser and is never sent to a server

## Planned

- Typing input for `Scanner` programs directly in the output panel, then saving code, starter examples, shareable links, and a mobile layout
- Guide buttons that insert code, like a `for` loop, with a dropdown that explains it
- More languages after Java: JavaScript, Python and C/C++, one at a time
